# workflow-editorial-agents

Équipe d'agents IA qui prépare un post LinkedIn pour une marque : veille sur l'actualité et sur des dépôts de code publics, angle, texte et visuel aux couleurs de la marque. Chaque affirmation renvoie à une source ; un humain valide, puis publie toujours à la main.

L'outil est générique : la marque est un profil local, non versionné. Ce dépôt ne contient qu'un profil d'exemple fictif.

**Statut : en cours de cadrage.** Le besoin est dans le [cahier des charges](docs/cahier-des-charges-fonctionnel.md), l'ordre des travaux dans le [plan](docs/plan.md).

Initialisé avec la chaîne de développement agentique [agentic-dev-workflow](https://github.com/yanis-vroland/agentic-dev-workflow).
